# All In One x Imran — Official Portfolio & Creator Hub

Lightweight, mobile-first single-page portfolio built for **All In One x Imran**, **Unseen Tech Bangla**, **Unseen Kingdom KSA**, and **openworldxbd**.

## Files Included
- `index.html` — Main website entry file (renamed from `Premium Portfolio.html` for GitHub Pages & Vercel auto-deployment).
- `vercel.json` — Clean URL and caching configuration for Vercel.
- `README.md` — Repository overview and deployment steps.

## How to Upload on GitHub (Mobile Browser)
1. Open your GitHub repository (`openworldxbd` or your portfolio repo).
2. Tap **Add file** → **Upload files**.
3. Upload `index.html`, `vercel.json`, `README.md`, and your transparent portrait image renamed as `avatar.png`.
4. Tap **Commit changes** — Vercel or GitHub Pages will automatically deploy your site live.
